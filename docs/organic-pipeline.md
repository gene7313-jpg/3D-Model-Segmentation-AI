# Organic repair → split → pins pipeline

Branch: `feature/organic-repair-split-pins`

Apply the printability nodes to **existing** organic projects under `data/raw/organic/<slug>/` (already generated by trellis-mac / `generate-from-image`), without regenerating from photos.

## Pipeline nodes

```text
[existing print STL]
        │
        ▼
   repair (auto/voxel)     → source_repaired.stl   (watertight)
        │
        ▼
   split (mid-plane)       → parts/part_XX.stl     (P1S fit)
        │
        ▼
   pins (optional)         → pin + socket on cut faces
        │
        ▼
   meta.yaml update
```

| Node | Module / CLI | Purpose |
|------|----------------|---------|
| **repair** | `repair.py` via `--repair-mode basic\|voxel` | **basic** (default) preserves detail; **voxel** forces watertight but is lossy/blocky |
| **split** | `organic_cut.py` | Longest-axis mid-plane until parts fit (or `--force-split`) |
| **pins** | `pins.py` via `--with-pins` | Male pin + female socket on mating cut faces (run on basic-cut meshes) |
| **batch** | `process-organic` / `process-organic-batch` | Run nodes on one or many existing slugs |

**Quality note:** Do **not** use `--repair-mode auto/voxel` for display/print detail. `auto` now equals `basic`. Coarse voxel remesh (~2 mm pitch) turns shoes into LEGO; only use `--repair-mode voxel --voxel-resolution 160+` when you explicitly need a watertight shell.

## Existing project prerequisites

Each slug should already have at least one of:

- `meta.yaml` with `print_stl: source_120mm.stl` (or similar), or
- `source_*mm.stl`, or
- `source.stl`

Typical after Phase C:

```text
data/raw/organic/<slug>/
  source_image.png
  source.glb
  source.stl
  source_120mm.stl
  meta.yaml
```

## Single project

```bash
cd ~/Desktop/Projects/3D-Model-Segmentation-AI
source .venv/bin/activate
git fetch origin
git checkout feature/organic-repair-split-pins
pip install -e .

# Repair + split + pins on an existing slug
segmentation-ai process-organic data/raw/organic/shoe_cli_full \
  --force-split \
  --repair-mode basic \
  --with-pins
```

Equivalent lower-level command:

```bash
segmentation-ai cut-organic data/raw/organic/shoe_cli_full \
  --force-split --repair-mode basic --with-pins
```

## Batch all organic slugs

```bash
segmentation-ai process-organic-batch data/raw/organic \
  --force-split \
  --repair-mode auto \
  --with-pins
```

Skips folders that lack a print STL. Continues on error unless `--fail-fast`.

## Pin defaults

From `config/defaults.yaml` → `mechanical` / `organic_cut.pins`:

| Setting | Default | Notes |
|---------|---------|--------|
| `pin_diameter_mm` | 3.0 | Male pin OD |
| `pin_clearance_mm` | 0.2 | Female hole is diameter + clearance |
| `pin_length_mm` | 6.0 | Engagement length |
| `pin_count` | 2 | Along major axis of cut face |
